Privacy Policy — Tiltzy

Last updated: November 5, 2026

Tiltzy is a tilt-to-guess party game. It has no account system and no sign-in — there is nothing to log into, and we never see your name, email address, or any other personal identifier.

The on-device tier (default)

By default, decks are generated entirely on your device using a local AI model (Gemma, run on-device via Google's LiteRT-LM runtime). In this mode, nothing you type is ever sent anywhere. The model file itself (~a few hundred MB) is downloaded once through Google Play's Asset Delivery service, the same system Android uses for app updates — that download doesn't include anything you've typed or played.

The optional cloud tier

If you switch to the cloud tier (used for harder/higher-quality decks, and for Image mode), the topic you type and a few generation settings (difficulty, format, and which words to avoid repeating) are sent to our backend, which forwards your topic text to Anthropic's Claude API to generate the deck, and — for Image mode — to OpenAI's image API to generate accompanying images. These providers process that text/image request on our behalf and under their own privacy terms; we don't send them your name or any other personal identifier, only the topic text itself.

Permissions

Tiltzy requests only the Internet permission, used solely for the optional cloud tier and the one-time on-device model download described above.

Requesting deletion of your data

Because there's no account, we can't verify a deletion request automatically. To request deletion, email mikitad@gmail.com. If you've purchased a credit pack, include the Google Play order number from your purchase confirmation email so we can locate and delete the matching record (balance and purchase history) — we'll do this within a few days. If you've never purchased credits, there's no record identifiable to you beyond what already resets automatically if you uninstall the app. On-device data (your saved decks, skin choice) is deleted simply by uninstalling the app.

Children's privacy

Tiltzy is not directed at children and does not knowingly collect personal information from anyone, regardless of age.
